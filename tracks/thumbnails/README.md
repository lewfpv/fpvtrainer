# Pályaképek

A pályakép fájlneve egyezzen meg a GLB vagy glTF fájl kiterjesztés nélküli
nevével. Támogatott formátumok: `.webp`, `.jpg`, `.jpeg`, `.png`.

Példák:

- `tinyhouse.glb` → `tinyhouse.webp`
- `game_room.glb` → `game_room.jpg`

Ha egy pályához nincs kép, a pályaválasztó automatikus helyőrzőt jelenít meg.
